# Haschisch Café (haschischcafe.de)

Category: cannabis

## Concept
A neutral, factual information site about Germany's cannabis law (Cannabisgesetz, in force since April 2024): what adults may possess and grow, how Anbauvereinigungen (cannabis social clubs) work, where consumption is prohibited (near schools, minors), youth protection and harm reduction with links to official sources (BMG, BZgA). No sales, no promotion of consumption, 18+ notice. Clear disclaimer that it is not legal advice.

## Look
Coffee-house calm: espresso brown, cream and muted olive, an elegant serif with a clean sans; feels like a quiet café, not a party.

Repo: https://github.com/frankinkua/haschischcafe.de

## Project Structure
- `index.html`: The main landing page containing all factual information and the interactive scenario selector.
- `impressum.html`: The legal notice (Impressum) with placeholders.
- `datenschutz.html`: The privacy policy explaining the zero-data-collection approach.
- `404.html`: Custom error page.
- `style.css`: All styles (supporting both light and dark modes).
- `script.js`: Vanilla JavaScript for the age gate and interactive scenario selector.
- `favicon.svg`: The site's scalable vector icon.
- `sitemap.xml` & `robots.txt`: SEO files.
- `CNAME`: Configuration for GitHub Pages custom domain.
